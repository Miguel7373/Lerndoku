
SonarQube ist einTool zur kontinuierlichen Inspektion von Codequalität. Es dient dazu, den Quellcode von Softwareprojekten auf verschiedene Arten von Problemen zu analysieren und zu überwachen.

**Code-Smells**: Code Bereiche die zwar korrekt funktionieren, aber möglicherweise verbesserungswürdig sind.
**Bugs**: Potenzielle Fehler im Code, die zu unerwartetem Verhalten führen können. 
**Sicherheitslücken**: Schwachstellen im Code, die für Angriffe ausgenutzt werden könnten.
**Coverage**: Messung der Testabdeckung deines codes.


Einsatzbereiche  SonarQube wird häufig in Softwareentwicklungsprojekten eingesetzt, um die Codequalität zu sichern und die Anzahl von Fehlern, Schwachstellen und ineffizienten Codeabschnitten zu reduzieren. Es ist ein wichtiges Werkzeug für Entwicklerteams, die Wert auf sauberen und wartbaren Code legen.`

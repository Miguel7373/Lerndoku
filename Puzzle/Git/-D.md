Das Target ist der bestimmte bereich was gernnt wird

#### ``` rm -rf target ```
```rm``` steht hier für remove
```-rf ``` dar r steht für **recursive** und macht das rm alles removed sogar directoryis und nicht nur einzelne Files
	  das f steht für **Force** und macht, dass es einfach gelöscht wird, auch wenn Warnungen aufkommen
```Target ``` zeigt dir dann an was genau du löschen willst in dem fall ist target im intellij der Ordner der alle dateien des bild prozesses gespeichert werden

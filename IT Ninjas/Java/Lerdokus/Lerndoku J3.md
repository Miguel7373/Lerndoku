# Objektorientiertes Design in Java

## Vererbung

- Vererbung ermöglicht die Ableitung neuer Klassen von bestehenden Klassen.
- Vererbung folgt dem IS-A-Prinzip und bildet hierarchische Beziehungen zwischen Klassen.
- Vererbung ermöglicht die Wiederverwendung von Code und die Erstellung von Klassenhierarchien.

## Das Schlüsselwort `extends`

- In Java wird Vererbung mit dem Schlüsselwort `extends` implementiert.
- Eine abgeleitete Klasse erbt Attribute und Methoden von ihrer Basisklasse.

## Das Schlüsselwort `super`

- Das Schlüsselwort `super` ermöglicht den Zugriff auf Felder, Konstruktoren und Methoden der Superklasse.
- Es wird verwendet, um den Konstruktor der Oberklasse aufzurufen oder eine Methode aus der Oberklasse aufzurufen.

## Beziehungen

- In Java gibt es verschiedene Arten von Beziehungen zwischen Objekten, darunter Generalisierung, Aggregation, Assoziation und Abhängigkeit.


## Überschreiben (Overriding)

- Überschreiben ermöglicht es, das Verhalten von Methoden in Subklassen neu zu definieren.
- Eine überschreibende Methode muss die Signatur der Superklasse-Methode beibehalten.

## Abstraktion

- Abstraktion bezieht sich auf das Bereitstellen von Funktionalität, ohne die Details der Implementierung preiszugeben.
- Abstrakte Klassen und Schnittstellen (Interfaces) sind Werkzeuge zur Erreichung von Abstraktion.

## Interfaces

- Interfaces definieren einen Satz von Methoden, die von Klassen implementiert werden müssen.
- Interfaces dienen als Verträge, die von implementierenden Klassen erfüllt werden müssen.

## Kapselung

- Kapselung verbirgt sensible Daten und Implementierungsdetails einer Klasse vor Benutzern.
- Kapselung wird erreicht, indem Klassenattribute als privat deklariert werden und öffentliche Methoden zur Interaktion mit diesen Attributen bereitgestellt werden.

Das Verständnis dieser Konzepte ist entscheidend für die Entwicklung von Java-Anwendungen im objektorientierten Stil.

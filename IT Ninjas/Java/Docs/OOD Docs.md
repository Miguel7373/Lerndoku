- **Vererbung** möglich Hierarchie herzustellen und das zerstört fast alle redundante Codes
- **Polymorphismus** ist eine Sprachstruktur, nach der beim Zugriff auf Methoden mit gleicher Signatur diese unterschiedliche Ergebnisse liefern.
- **Abstraktion** ist eine Methode, bei der durch Reduzieren oder Entfernen von Merkmalen nur die wesentlichen Eigenschaften erhalten bleiben.
- **Kapselung** ermöglicht es den Zugriff auf Methoden und Attributen von Klassen zu kontrollieren.

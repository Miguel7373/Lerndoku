* `var`, `let`, `const`: Zur Deklaration von Variablen und Konstanten.
* `console.log`: Zum Ausgeben von Nachrichten in der Entwicklerkonsole.
* `if`, `else if`, `else`: Zur Implementierung von bedingten Anweisungen.
* `for`, `while`: Zur Implementierung von Schleifen.
* `function`: Zur Deklaration von Funktionen.
* `return`: Zur Rückgabe von Werten aus einer Funktion.
* `Array`: Zur Erstellung und Manipulation von Arrays.
* `Object`: Zur Erstellung und Manipulation von Objekten.
* `typeof`: Zur Überprüfung des Datentyps einer Variable.
* `try`, `catch`, `finally`: Zur Implementierung von Fehlerbehandlungsroutinen.
* `import`, `export`: Zur Verwendung von Modulen in JavaScript (ES6+).
* `map`, `filter`, `reduce`: Zur Funktionalen Programmierung mit Arrays.
* `Promise`: Zur asynchronen Programmierung und Verwaltung von asynchronen Operationen.

* `JSON.parse`, `JSON.stringify`: Zur Konvertierung von JSON-Daten in JavaScript-Objekte und umgekehrt.
* `Math`: Zur Durchführung mathematischer Operationen.
* `Date`: Zur Arbeit mit Datums- und Zeitangaben.
* `setInterval`, `setTimeout`: Zur Ausführung von Code in bestimmten Zeitintervallen.
* `addEventListener`: Zur Hinzufügung von Event-Handlern zu DOM-Elementen.
* `document.querySelector`, `document.getElementById`: Zur Auswahl von DOM-Elementen.
* `alert`: Zur Anzeige einer Benachrichtigung in einem Dialogfeld im Browser.
* `onclick`: Zur Zuweisung von Ereignissen beim Klicken auf ein HTML-Element.

## DOM-Elemente
- Mit JavaScript kannst du das Erscheinungsbild und Verhalten einer Webseite dynamisch anpassen, indem du Elemente hinzufügst, entfernst oder bearbeitest, basierend auf Benutzerinteraktionen.
## Functions 
- JavaScript-Funktionen sind wie kleine Helfer, die spezifische Aufgaben erledigen können, und du kannst sie aufrufen, wann immer du ihre Hilfe benötigst, um diese Aufgaben zu erledigen.
## JSON
- JSON ist ein weit verbreitetes Datenformat zur Repräsentation strukturierter Informationen. Es basiert auf einer einfachen Syntax, die sowohl von Menschen als auch von Maschinen leicht verstanden werden kann. JSON-Daten bestehen aus Schlüssel-Wert-Paaren und geordneten Listen von Werten.
## Promises
- JavaScript-Promises sind asynchrone Programmierungsmechanismen, die die Ausführung von Code blockieren, bis eine Operation abgeschlossen ist, und dann entweder erfolgreich oder fehlerhaft zurückkehren.

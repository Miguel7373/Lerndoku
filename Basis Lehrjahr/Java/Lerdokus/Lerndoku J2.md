# Objektorientierte Programmierung (OOP)

- OOP nutzt Klassen als Baupläne für Objekte.
- Klassen beinhalten Felder und Methoden.
- Objekte werden mit Konstruktoren erstellt.

## Java Zugriffsmodifikatoren

- Private, Public, Protected und Package-Private sind Zugriffsmodifikatoren.
- Sie steuern die Sichtbarkeit von Feldern und Methoden.

## Felder und Methoden

- Es gibt statische und nicht-statische Felder.
- Konstruktoren initialisieren Objekte.
- Methoden ändern den Zustand von Objekten.

## Weitere Konzepte

- Getter, Setter, equals(), hashCode() und Enums sind wichtige Konzepte.

## Zusammenfassung für Listen und Streams

- Java-Listen sind Container für Objekte.
- ArrayList ist eine dynamische Array-Klasse.
- Streams ermöglichen funktionale Operationen auf Listen.
- Lambda-Ausdrücke und Methodenreferenzen vereinfachen die Codierung.
- Methoden wie `forEach()`, `sorted()` und `collect()` erleichtern die Verarbeitung von Streams.

Diese Zusammenfassung enthält die Grundlagen von OOP und wichtige Konzepte für die Arbeit mit Listen und Streams in Java.

## Java Generics Grundlagen

### Einführung

- Generics ermöglichen parametrisierte Datentypen in Java und bieten Typsicherheit.

### Warum Generics?

- Generics erlauben wiederverwendbaren Code und verhindern Laufzeitfehler.
- Sie eliminieren unnötiges Typ-Casting.

### Generische Klassen und Methoden

- Generische Klassen verwenden Typparameter und erlauben die Verwendung verschiedener Datentypen.
- Generische Methoden arbeiten ähnlich und können mit unterschiedlichen Typen aufgerufen werden.

### Bounded Typparameter

- Bounded Typparameter schränken erlaubte Datentypen ein.
- "extends" erlaubt Kindtypen, "super" erlaubt Supertypen.

### Wildcards und Type Erasure

- Wildcards wie `<?>` bieten Flexibilität.
- Generics werden zur Laufzeit gelöscht (Type Erasure), um Abwärtskompatibilität zu wahren.

In dieser Zusammenfassung werden die Kernkonzepte von Generics in Java behandelt.

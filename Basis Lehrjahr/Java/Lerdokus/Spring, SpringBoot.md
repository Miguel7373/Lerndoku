# Spring

## Vor- und Nachteile der Framework-Nutzung:
- **Vorteile:** Vereinfachter Entwicklungsprozess, standardisierte Struktur, verbesserte Wartbarkeit und Erweiterbarkeit.
- **Nachteile:** Lernkurve, potenzielle Overhead-Kosten, eingeschränkte Flexibilität.

## Inversion of Control (IoC) und Dependency Injection (DI):
- IoC kehrt den Kontrollfluss um und wird in Spring durch DI implementiert.
- DI ermöglicht es, Abhängigkeiten automatisch zu injizieren, wodurch eine lose Kopplung erreicht wird.

## Beans in Spring:
- Beans sind Kernkomponenten, die vom Spring IoC-Container verwaltet werden.
- Sie können über XML- oder Java-Konfiguration erstellt werden und verschiedene Scopes haben.

## Scopes von Spring-Beans:
- Singleton, Prototype, Request, Session, Application.

## Verwendung von Spring-Bean-Annotationen:
- @Service, @Configuration, @Component, @Repository, @Controller.

## Spring Profile:
- Ermöglicht die Aktivierung bestimmter Beans basierend auf Profilen.
- Beans können entsprechend der aktiven Profile konfiguriert werden.

# SpringBoot
- Spring Boot ist ein Projekt von Spring, das entwickelt wurde, um die Verwendung von Spring zu vereinfachen. Durch den Spring Initializr kann ein Spring Boot Projekt erstellt werden, wobei zusätzliche Abhängigkeiten und Funktionalitäten hinzugefügt werden können.

## Hauptaspekte von Spring Boot:

### 1. Autokonfiguration:
- Spring Boot initialisiert Anwendungen mit voreingestellten Abhängigkeiten, um Zeit zu sparen und Konfigurationsfehler zu vermeiden.

### 2. Meinungsansatz:
- Spring Boot wählt automatisch Pakete und Standardwerte aus, um Entwicklern Entscheidungen abzunehmen und die Konfiguration zu vereinfachen.

### 3. Eigenständige Anwendungen:
- Spring Boot kann eigenständige Anwendungen erstellen, die ohne externen Webserver ausgeführt werden können.

## Unterschied zwischen Spring Framework und Spring Boot:
- Spring Boot bietet zusätzliche Komfortfunktionen wie schnellen Projektstart, Starter-Pakete und eingebettete Server.

## Empfehlung:
- In den meisten Fällen wird die Verwendung von Spring Boot empfohlen. Spring Boot ermöglicht den Zugriff auf das Annotationssystem des Spring Frameworks und die problemlose Hinzufügung von Abhängigkeiten.

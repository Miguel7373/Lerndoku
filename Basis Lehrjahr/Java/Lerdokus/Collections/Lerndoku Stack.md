# Stack in Java: Eine Übersicht

## Einführung

Die `java.util.Stack` ist eine Datenstruktur, die nach dem Last-In-First-Out (LIFO)-Prinzip funktioniert, was bedeutet, dass das zuletzt hinzugefügte Element als erstes entfernt wird. Im Deutschen könnte man einen Stack als "Stapel" übersetzen.

## Methodenübersicht


- `push(E item)`: Fügt ein Element oben auf den Stack hinzu.
- `pop()`: Entfernt das oberste Element und gibt es zurück.
- `peek()`: Gibt das oberste Element zurück, ohne es zu entfernen.
- `empty()`: Gibt `true` zurück, wenn der Stack leer ist.
- `search(Object o)`: Sucht ein Element im Stack und gibt die Position zurück (1-basiert).

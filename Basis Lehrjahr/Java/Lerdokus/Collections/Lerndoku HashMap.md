# HashMap in Java: Eine Übersicht

## Einführung

Die `java.util.HashMap` ist die gebräuchlichste Implementierung einer Map in Java. Maps werden verwendet, um Zuweisungen von Schlüsseln zu Werten zu speichern. In einer HashMap ist der Schlüssel immer eindeutig, und bei gleichem Schlüssel wird die erste Zuweisung überschrieben.


## Collection Ansichten

Eine HashMap bietet drei Collection Ansichten auf den gespeicherten Inhalt:

- `keySet()`: Set auf alle Schlüssel
- `values()`: Collection auf alle Werte
- `entrySet()`: Set auf alle Schlüssel-Werte Zuweisungen

# Zusammenfassung: Testing in der Softwareentwicklung
## Testarten

- Manuelles und automatisiertes Testen
- Unit-Tests, Integrations-Tests, End-to-End-Tests

## JUnit 5

- Plattform, Jupiter, Vintage
- Annotations: @Test, @ParameterizedTest, @RepeatedTest, @DisplayName, @Disabled, @TestMethodOrder, @Order, @BeforeEach, @AfterEach, @BeforeAll, @AfterAll

## Parametrisierte Tests

- Wiederverwendung von Testmethoden mit verschiedenen Parametern

## Mockito-Framework

- Einbindung durch manuellen Download oder Maven
- Begriffe: Mocks, Spies, Mockito-Annotationen

## Wichtige Mockito-Methoden

- Mockito.when kombiniert mit Mockito.thenReturn
- Mockito.verify für die Überprüfung von Interaktionen

## Test Driven Development (TDD)

- Zyklus: Test schreiben (fehlschlagen lassen), Code schreiben (Test erfolgreich machen), Refactoring
- Fördert schrittweise und getestete Softwareentwicklung

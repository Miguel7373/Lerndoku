Als Erstes muss ein File erstellt werden, das dem Web erlaubt, den USB zu verwenden. 

Das kannst du mit dieser Doku von micro:bit machen, folge einfach dem Linux teil.
https://support.microbit.org/support/solutions/articles/19000105428-webusb-troubleshooting 	
`gsettings set org.gnome.desktop.session idle-delay 0`

Ebenfalls sollten alle wichtigen Updates immer gemacht worden sein.

Doch, wenn es dann immer noch nicht funktioniert, musst du noch auf den Chrom-Browser und die Flags, die etwas mit dem Web USB zu tun haben, aktivieren. Wenn du in Chrom `chrome://flags` eingibst, kommst du auf die Seite, die alle Flags regeln.
